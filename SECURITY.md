# Security policy

## Supported versions

Delivery Boy has not published its first public beta. Until then, only the
current `main` branch receives security fixes.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a
public issue for a suspected vulnerability or include secrets, credentials, or
private logs in an issue.

Include the affected command or config field, the impact, and a small way to
reproduce the problem without real credentials. We will confirm receipt before
discussing it in public.
